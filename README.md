# 🌱 디지털 새싹 신규 교육 프로그램 개발 및 동향 제안 대시보드

> 초·중·고 학생들의 AI·디지털 역량 함양을 위해 설계된 **디지털 새싹(Digital Saessak)** 사업의 15대 기존 교육 프로그램을 체계적으로 분석하고, 실제 운영기관으로서 우수 평가를 확보할 수 있는 **독창적인 신규 교육 프로그램 3종(각 12차시 상세안 포함)**을 제안하는 인터랙티브 웹 대시보드 기획서입니다.

## ✨ 핵심 기능 (Core Features)
1.  **15대 기존 프로그램 분석**: 누리집 내에 산재한 AI, IoT, 메타버스 교육 트렌드를 분류하고, 카테고리별 동적 필터링을 통해 시장 동향을 한눈에 제공합니다.
2.  **독창적 신규 프로그램 3종 기획**:
    *   🚀 **AI 스페이스 엑스퍼트**: 인공지능과 우주 탐사 로봇 프로젝트 (중·고등용)
    *   🌿 **에코 스마트 가디언**: IoT & 빅데이터 기반 지구 환경 수호대 (초등 고학년~중학용)
    *   ♿ **넥스트 버추얼 빌더**: 메타버스와 디지털 트윈 배리어 프리 스쿨 (초등 고학년~고등용)
3.  **12차시 인터랙티브 타임라인**: 팝업 모달을 통해 도입, 심화, 해커톤으로 연결되는 체계적인 12차시 상세 계획표를 그래픽 타임라인 형식으로 전시합니다.
4.  **원클릭 마크다운 복사**: 각 제안 프로그램의 전체 요약본과 1~12차시 디테일 기획안을 클립보드로 즉시 복사하여 한글/워드 공문서 및 제안서 작성 시 실무에 바로 사용할 수 있도록 지원합니다.
5.  **프리미엄 듀얼 테마 지원**: 트렌디한 IT 감성의 '다크 모드'와 모던하고 미니멀한 '라이트 모드'를 우상단 스위치를 통해 자유롭게 전환하여 볼 수 있습니다.

## 🛠️ 기술 스택 (Technology Stack)
*   **Frontend**: HTML5, Vanilla CSS3 (Custom Variables & Transitions), Vanilla JavaScript
*   **Design & System**: Glassmorphism, Dual Theme Engine, Responsive Grid Layout
*   **Fonts & Icons**: Pretendard, Outfit, FontAwesome 6.4.0
*   **Hosting & Deployment**: Vercel CLI, GitHub Actions (GitHub Pages)

## 💻 로컬 실행 방법 (Local Run)
별도의 빌드나 서버 환경 설정이 전혀 필요 없는 단일 완성형 정적 HTML 파일 구조입니다.

1.  본 저장소를 클론(Clone)합니다:
    ```bash
    git clone https://github.com/ilhoonseo/dissack.git
    cd dissack
    ```
2.  `index.html` 파일을 더블 클릭하여 크롬이나 엣지 등 사용하는 웹 브라우저에서 바로 실행합니다.
